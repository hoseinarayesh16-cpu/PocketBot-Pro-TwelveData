PocketBot Pro — Twelve Data

1. پروژه را روی Render به عنوان Web Service با Node.js منتشر کنید.
2. Build Command: npm install
3. Start Command: npm start
4. در Environment متغیر TWELVE_DATA_API_KEY را با کلید شخصی خود تنظیم کنید.
5. پس از انتشار، /health را باز کنید و configured:true را بررسی کنید.
6. صفحه اصلی را باز کنید و نماد و تایم‌فریم را انتخاب کنید.

محدودیت: API Twelve Data سهمیه و محدودیت پلن دارد؛ داده‌ها لزوماً با Pocket Option برابر نیستند. کلید را در HTML یا مخزن عمومی قرار ندهید.
